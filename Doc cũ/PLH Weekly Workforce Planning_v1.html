2. Workflow Architecture

Day Type Analysis → Demand-Aware → Demand Curve Optimizer → Weekly Roster Engine. Demand được tối ưu trước khi assign nhân sự.

flowchart TD
  A[Import Inputs]

  A --> H[Historical Data]
  A --> AV[Availability]
  A --> WF[Weekly Forecast]
  A --> OC[Open/Close Staffing]
  A --> EM[Employee Master]

  H --> DTA
  WF --> DTA
  SC --> TCPH

  subgraph DTA[Day Type Analysis]
    DTA1[Tạo day type factor]
    DTA2[Tạo baseline demand theo ngày]
    DTA3[Tạo hourly demand theo slot]
    DTA1 --> DTA2 --> DTA3
  end

  DTA --> TCPH

  subgraph TCPH[TCPH-aware Demand Generation]
    TCPH1[Dùng TCPH Target từ Cấu hình]
    TCPH2[Kiểm soát demand theo target]
    TCPH1 --> TCPH2
  end

  TCPH --> DAL

  subgraph DAL[Demand-Aware Layer]
    DAL1[Kiểm tra độ nhạy demand theo ngày/slot]
    DAL2[Điều chỉnh demand nếu lệch so với target]
    DAL1 --> DAL2
  end

  DAL --> DCO

  subgraph DCO[Demand Curve Optimizer]
    DCO1[Làm mượt curve theo ngày]
    DCO2[Tối ưu demand theo peak / valley / open-close window]
    DCO1 --> DCO2
  end

  DCO --> ODD[Optimized Daily Demand]
  ODD --> WRE
  AV --> WRE
  EM --> WRE
  SC --> WRE

  subgraph WRE[Weekly Roster Engine]
    WRE1[Assign manager open / close hard coverage]
    WRE2[Validate manager weekly hour]
    WRE3[Assign manager day off if safe]
    WRE4[Assign fixed employees]
    WRE5[Fill PT coverage / balance PT hours]
    WRE6[Optimize roster efficiency without breaking manager locks]
    WRE7[Rule set: manager coverage, FT fixed 8h, PT 4-8h, manual open/close headcount, availability, TCPH safety band, KPI references]
    WRE1 --> WRE2 --> WRE3 --> WRE4 --> WRE5 --> WRE6
    WRE7 -. controls .-> WRE1
    WRE7 -. controls .-> WRE6
  end

  WRE --> FWR[Final Weekly Roster]
  FWR --> OUT[KPI Summary / Coverage Analysis / Recommendation]

2. Weekly Forecast

Weekly Forecast feeds Day Type Analysis before TCPH-aware demand generation.

3. Day Type Analysis

Creates day type factor, daily baseline demand, and hourly demand by slot.

4. Weekly Roster

Assigns people only after Optimized Daily Demand is finalized; keeps manager, FT, PT, manual open/close headcount, availability, and TCPH minimum-floor rules.

5. Demand & ADTC By Week

Optimized daily demand and ADTC after TCPH-aware Demand Generation, Demand-Aware Layer, and Demand Curve Optimizer.

6. Coverage Analysis

Demand, Scheduled, Gap, CPH, Status.

7. Recommendation

KPI Summary, Coverage Analysis, Recommendation after final weekly roster.
